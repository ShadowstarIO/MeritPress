# Merit Press 1.0
Made public after being updated to 'Service Press', now free to use at https://press.shadowstar.io/ for your service, real or play.
Thank you to all those out there who do serve our countries and communities.

Award ribbon studio for Eclipse RP / LSPD forum flair.

Design one merit ribbon in the browser, then export it. Work stays on the machine — no account, no database. The named save, palettes, and the ribbon on the press live in local cache. Export JSON to back them up or move them.

## Studio

- Grab empty space (or hold Space) to pan the artboard. Zoom does not shrink the bar to fit — it clips, so you can work in tight detail.
- Stripe column-line resize (spreadsheet neighbors only), plus add / equalize / mirror / split / clone / delete.
- Repeat and scale on stripes; repeat X/Y on any layer.
- Finishes on stripes and devices (satin, hash, metal, enamel, leather, glow, worn, and more).
- Overlay wear on a device: scratches, dirt, mud, damage, torn, sparkle, wet, dust, rust. The same list on the left covers the whole ribbon.
- Ruler along the artboard, in ribbon pixels. Grid is its own menu.
- Devices, glyphs (letters, roman, stars, marks, arrows), shapes, and SVG / image import.
- Adaptive grid, decimal snap, smart snap.
- Tools: select, move, marquee, brush, fill, erase, eyedrop, stamp.

## Export

PNG is rendered at 8× then downsampled.

- **Forum** — 1× (236×66 phpBB flair)
- **4× / 8×** — posting and print
- **SVG** — raster-embedded for finish fidelity
- **.meritpress** — the ribbon and its images, to move or back up
- **.meritpress.json** — a template of that ribbon
- **Stack** — cache up to five ribbons or uploads, arrange them, save one image

## Hosting

Client-only. Intended for [shadowstar.io](https://shadowstar.io), `merit.ecrp.link`, or Cloudflare Workers.
